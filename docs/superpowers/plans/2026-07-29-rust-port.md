# Rust Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the four POSIX `sh` entrypoints and `lib.sh` with one compiled Rust binary, with no user-visible change in behaviour.

**Architecture:** A single binary `last` dispatching on `argv[1]` to four subcommands (`record-tab`, `record-workspace`, `jump-tab`, `jump-workspace`). Four modules with hard boundaries: `context.rs` validates the `HERDR_*` environment and computes state paths, `mru.rs` owns the most-recently-used list and knows nothing about Herdr, `herdr.rs` spawns the `herdr` CLI and parses its JSON and knows nothing about the MRU, and `main.rs` wires them together and owns every exit-code decision.

**Tech Stack:** Rust 2021, `serde` + `serde_json` (CLI response parsing), `tempfile` (atomic replace). Tests are `cargo test` for logic plus the existing POSIX `test.sh` for entrypoint behaviour.

**Spec:** `docs/superpowers/specs/2026-07-29-rust-port-design.md`

**Status of the code in this plan:** every Rust block below was assembled into a scratch crate and run before this plan was committed. `cargo test` → 38 passed, 0 failed (the count is 41 as executed — see NOTE ON TEST COUNTS below). `cargo clippy --all-targets -- -D warnings` → clean. An end-to-end pass against a stub `herdr` confirmed MRU ordering, the A→B→A toggle, and all three guard paths (silent, exit 0, zero `herdr` invocations, no files created). The blocks are transcription-ready, not sketches.

One caveat from that dry run, worth knowing before Task 5: the first end-to-end attempt reported a guard failure that was an artifact of the probe harness, not the code. It used a prefix assignment (`HERDR_TAB_ID=... "$BIN" jump-tab`) without unsetting the sibling variable, so the **ambient** `HERDR_WORKSPACE_ID` from the live Herdr session leaked in and the guard never ran. This is the same trap BUILD-NOTES records at Task 3. It is the reason `new_sandbox` must keep its `unset` line byte-for-byte.

## Global Constraints

- `MRU_LIMIT` is exactly `8`.
- Plugin id stays `m4salah.last`. Manifest version becomes `0.2.0`. `min_herdr_version` stays `0.7.5`.
- `platforms = ["linux", "macos"]`. No Windows.
- Binary is named `last`; Cargo package is `herdr-plugin-last`.
- Dependencies are exactly `serde`, `serde_json`, `tempfile`. Do not add others.
- The session key is the **full** `HERDR_SOCKET_PATH` with every `/` replaced by `_`, never the basename. When `HERDR_SOCKET_PATH` is unset or empty, the key is the literal string `default`.
- On-disk state format is unchanged: newline-terminated ids, most recent first, at `$HERDR_PLUGIN_STATE_DIR/<session-key>/workspaces` and `$HERDR_PLUGIN_STATE_DIR/<session-key>/tabs/<workspace-id>`.
- **Exit policy.** `record-*` exits 0 silently on a guard condition (missing/empty `HERDR_WORKSPACE_ID`, `HERDR_TAB_ID`, or `HERDR_PLUGIN_STATE_DIR`) and exits **non-zero** on a genuine I/O failure. `jump-*` **always** exits 0 and swallows every error.
- **Nothing is written to stdout or stderr on any guard or success path.** The `herdr` CLI's own output is always captured via `.output()` and discarded, never inherited. The only permitted write is a single stderr line on a `record-*` I/O failure.
- Environment variables are treated as absent when unset **or empty**, matching shell `${VAR:-}` and `${VAR:?}` semantics.
- `Cargo.lock` is committed.

```rust
use std::path::PathBuf;

pub struct Context {
    pub state_dir: PathBuf,
}

impl Context {
    /// Returns `None` when `HERDR_PLUGIN_STATE_DIR` is unset or empty, which is
    /// the caller's signal to exit 0 silently.
    ///
    /// The shell version expressed this as `${HERDR_PLUGIN_STATE_DIR:?}`, which
    /// aborted only the `$( )` subshell it ran in and let the parent continue
    /// with an empty path. Returning an `Option` the caller must destructure
    /// makes that failure mode inexpressible.
    pub fn from_env() -> Option<Context> {
        let state_dir = env_id("HERDR_PLUGIN_STATE_DIR")?;
        let socket = env_id("HERDR_SOCKET_PATH").unwrap_or_else(|| "default".to_string());
        Some(Context {
            state_dir: PathBuf::from(state_dir).join(session_key(&socket)),
        })
    }

    pub fn workspaces_file(&self) -> PathBuf {
        self.state_dir.join("workspaces")
    }

    pub fn tabs_file(&self, workspace_id: &str) -> PathBuf {
        self.state_dir.join("tabs").join(workspace_id)
    }
}

/// The whole socket path is sanitised, not its basename. Named sessions live at
/// `~/.config/herdr/sessions/<name>/herdr.sock` and the default session at
/// `~/.config/herdr/herdr.sock`, so every session shares the basename
/// `herdr.sock`; keying on it would make concurrent sessions share one history.
pub fn session_key(socket_path: &str) -> String {
    socket_path.replace('/', "_")
}

/// Reads an environment variable, treating unset and empty as identical. This
/// matches the shell's `${VAR:-}` and `${VAR:?}` semantics, which the whole
/// plugin relies on.
pub fn env_id(name: &str) -> Option<String> {
    std::env::var(name).ok().and_then(non_empty)
}

fn non_empty(value: String) -> Option<String> {
    if value.is_empty() { None } else { Some(value) }
}
```

```rust
use std::fs;
use std::io::Write;
use std::path::Path;

pub const MRU_LIMIT: usize = 8;

/// Reads an MRU file, most recent first. A missing or unreadable file is an
/// empty list, never an error — a jump with no history is a normal no-op.
///
/// Blank lines are skipped. `record` cannot produce one, so a blank line can
/// only arrive by hand-editing, and dropping it here keeps every consumer free
/// of blank-id guards.
pub fn read(path: &Path) -> Vec<String> {
    fs::read_to_string(path)
        .unwrap_or_default()
        .lines()
        .filter(|line| !line.is_empty())
        .map(str::to_string)
        .collect()
}

/// Moves `id` to the front of the MRU file, deduplicating and capping the list.
///
/// A blank id is ignored so that a missing `HERDR_TAB_ID` cannot truncate the
/// history. Comparison is whole-value and literal, which is what the shell
/// version needed `grep -vxF`'s `-x` and `-F` flags to achieve.
pub fn record(path: &Path, id: &str) -> std::io::Result<()> {
    if id.is_empty() {
        return Ok(());
    }
    let mut entries = read(path);
    entries.retain(|entry| entry != id);
    entries.insert(0, id.to_string());
    entries.truncate(MRU_LIMIT);
    write_atomic(path, &entries)
}

/// Replaces `path` with `entries` atomically, so a concurrent reader never
/// observes a half-written list. The temp file is created in the destination
/// directory so the rename stays on one filesystem.
fn write_atomic(path: &Path, entries: &[String]) -> std::io::Result<()> {
    let dir = path.parent().ok_or_else(|| {
        std::io::Error::new(std::io::ErrorKind::InvalidInput, "path has no parent")
    })?;
    fs::create_dir_all(dir)?;
    let mut tmp = tempfile::NamedTempFile::new_in(dir)?;
    for entry in entries {
        writeln!(tmp, "{entry}")?;
    }
    tmp.persist(path).map_err(|err| err.error)?;
    Ok(())
}
```

```rust
/// The first MRU entry worth jumping to, or `None`.
///
/// Entries are filtered against the *live* current id rather than assuming the
/// head of the list is accurate, so a missed focus event cannot make the jump
/// land on the tab the user is already looking at.
///
/// Filtering against `live` is required rather than defensive: `herdr tab focus`
/// on a deleted tab exits 0, so a try-and-check-status fallback would silently
/// do nothing instead of moving on to the next candidate.
pub fn pick_target(path: &Path, current: &str, live: &[String]) -> Option<String> {
    read(path)
        .into_iter()
        .find(|id| id != current && live.iter().any(|candidate| candidate == id))
}
```

```rust
use serde::Deserialize;
use std::process::Command;

/// Every CLI response is an envelope carrying either `result` or `error`.
/// Modelling `result` as an `Option` means an error response deserialises to
/// `None` and degrades to an empty id list rather than failing.
#[derive(Deserialize)]
struct Envelope<T> {
    result: Option<T>,
}

#[derive(Deserialize)]
struct TabList {
    tabs: Vec<Tab>,
}

#[derive(Deserialize)]
struct Tab {
    tab_id: String,
}

#[derive(Deserialize)]
struct WorkspaceList {
    workspaces: Vec<Workspace>,
}

#[derive(Deserialize)]
struct Workspace {
    workspace_id: String,
}

pub fn parse_tab_ids(json: &str) -> Vec<String> {
    serde_json::from_str::<Envelope<TabList>>(json)
        .ok()
        .and_then(|envelope| envelope.result)
        .map(|list| list.tabs.into_iter().map(|tab| tab.tab_id).collect())
        .unwrap_or_default()
}

pub fn parse_workspace_ids(json: &str) -> Vec<String> {
    serde_json::from_str::<Envelope<WorkspaceList>>(json)
        .ok()
        .and_then(|envelope| envelope.result)
        .map(|list| {
            list.workspaces
                .into_iter()
                .map(|workspace| workspace.workspace_id)
                .collect()
        })
        .unwrap_or_default()
}

/// Herdr injects `HERDR_BIN_PATH` into plugin commands; falling back to `PATH`
/// keeps the binary runnable by hand.
fn herdr_bin() -> String {
    crate::context::env_id("HERDR_BIN_PATH").unwrap_or_else(|| "herdr".to_string())
}

/// Runs a `herdr` subcommand and returns its stdout, or `None` on any failure.
/// `.output()` captures both streams, so the CLI can never write to our
/// terminal.
fn run(args: &[&str]) -> Option<String> {
    let output = Command::new(herdr_bin()).args(args).output().ok()?;
    if !output.status.success() {
        return None;
    }
    String::from_utf8(output.stdout).ok()
}

pub fn live_tab_ids(workspace_id: &str) -> Vec<String> {
    run(&["tab", "list", "--workspace", workspace_id])
        .map(|json| parse_tab_ids(&json))
        .unwrap_or_default()
}

pub fn live_workspace_ids() -> Vec<String> {
    run(&["workspace", "list"])
        .map(|json| parse_workspace_ids(&json))
        .unwrap_or_default()
}

/// Focus calls are best effort. Failures are swallowed: a jump must never
/// interrupt the user or write to the terminal.
pub fn focus_tab(id: &str) {
    let _ = Command::new(herdr_bin()).args(["tab", "focus", id]).output();
}

pub fn focus_workspace(id: &str) {
    let _ = Command::new(herdr_bin())
        .args(["workspace", "focus", id])
        .output();
}
```

```rust
mod context;
mod herdr;
mod mru;

use context::{env_id, Context};
use std::process::ExitCode;

fn main() -> ExitCode {
    let Some(subcommand) = std::env::args().nth(1) else {
        return ExitCode::SUCCESS;
    };
    match subcommand.as_str() {
        // Record hooks surface a genuine write failure to Herdr's plugin log.
        "record-tab" => report(record_tab()),
        "record-workspace" => report(record_workspace()),
        // Jump actions are a best-effort convenience. A failed jump must never
        // interrupt the user, so every error is swallowed and the exit is
        // always 0. This asymmetry with the record hooks is deliberate.
        "jump-tab" => {
            jump_tab();
            ExitCode::SUCCESS
        }
        "jump-workspace" => {
            jump_workspace();
            ExitCode::SUCCESS
        }
        _ => ExitCode::SUCCESS,
    }
}

/// Guard conditions return `Ok(())` and exit 0 silently. Only a real I/O
/// failure reaches the error arm, where the message is what makes the failure
/// legible in Herdr's plugin log.
fn report(result: std::io::Result<()>) -> ExitCode {
    match result {
        Ok(()) => ExitCode::SUCCESS,
        Err(err) => {
            eprintln!("herdr-plugin-last: {err}");
            ExitCode::FAILURE
        }
    }
}

fn record_tab() -> std::io::Result<()> {
    let (Some(workspace), Some(tab)) = (env_id("HERDR_WORKSPACE_ID"), env_id("HERDR_TAB_ID"))
    else {
        return Ok(());
    };
    let Some(context) = Context::from_env() else {
        return Ok(());
    };
    mru::record(&context.tabs_file(&workspace), &tab)
}

fn record_workspace() -> std::io::Result<()> {
    let Some(workspace) = env_id("HERDR_WORKSPACE_ID") else {
        return Ok(());
    };
    let Some(context) = Context::from_env() else {
        return Ok(());
    };
    mru::record(&context.workspaces_file(), &workspace)
}

fn jump_tab() {
    let Some(workspace) = env_id("HERDR_WORKSPACE_ID") else {
        return;
    };
    let Some(context) = Context::from_env() else {
        return;
    };
    let current = env_id("HERDR_TAB_ID").unwrap_or_default();
    let live = herdr::live_tab_ids(&workspace);
    if let Some(target) = mru::pick_target(&context.tabs_file(&workspace), &current, &live) {
        herdr::focus_tab(&target);
    }
}

fn jump_workspace() {
    let Some(context) = Context::from_env() else {
        return;
    };
    let current = env_id("HERDR_WORKSPACE_ID").unwrap_or_default();
    let live = herdr::live_workspace_ids();
    if let Some(target) = mru::pick_target(&context.workspaces_file(), &current, &live) {
        herdr::focus_workspace(&target);
    }
}
```
